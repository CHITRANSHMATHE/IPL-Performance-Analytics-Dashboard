🏏 IPL Performance Analytics Dashboard — Tableau
**📌 Project Overview**

An interactive Tableau dashboard analyzing IPL match data from 2008–2019 to uncover trends in team performance, player statistics, venues, toss decisions, and match outcomes.

**🎯 Objectives**
Analyze team-wise and season-wise performance.
Identify top-performing players and teams.
Study venue and city-wise match trends.
Analyze the impact of toss decisions on match outcomes.
Compare batting and player performance metrics.

**📊 Key Insights**
12 IPL seasons analyzed from 2008–2019.
Mumbai Indians recorded 109 wins across the analyzed data.
Mumbai hosted 101 matches, making it one of the prominent venues.
Rohit Sharma recorded 14 Player of the Match awards in the analyzed dataset.

**🛠️ Tools & Technologies**
Tableau — Dashboard development & visualization
Data Analytics — Exploratory and comparative analysis
Data Visualization — KPIs, maps, bar charts, scatter plots, and trend analysis

**📈 Dashboard Features**
Team performance analysis
Player performance analysis
Venue & city analysis
Toss decision analysis
Season-wise trends
Interactive filters and KPIs
